# Exp3 - Course Info App

A simple Android application demonstrating a Master-Detail interface using Fragments. The app displays a list of programming and technology courses and provides detailed information when a course is selected.

## Features
- **Master-Detail Layout**: Utilizes a split-screen approach to show both the list and details simultaneously.
- **Course List**: Displays a variety of courses including Java, Python, Android, Machine Learning, and Cyber Security.
- **Detailed Information**: Provides descriptions for each selected course.

## Project Structure
- `MainActivity`: The main entry point that hosts the master and detail fragments.
- `CourseListFragment`: Handles the display of the course list.
- `DetailFragment`: Displays the details of the selected course.
